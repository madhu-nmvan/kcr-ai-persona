# Coding standards

All coding standards for this project live in the `coding-standards` skill at `.claude/skills/coding-standards/`.

**Load that skill** before writing code, reviewing changes, or answering questions about conventions.

## Agent skills

### Issue tracker

Issues live as local markdown files under `.scratch/<feature>/`. See `docs/agents/issue-tracker.md`.

### Triage labels

Default vocabulary — each triage role string equals its name. See `docs/agents/triage-labels.md`.

### Domain docs

Multi-context — `CONTEXT-MAP.md` at the root points to per-context `CONTEXT.md` files. See `docs/agents/domain.md`.
